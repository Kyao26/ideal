{ ***** SONUC: BLOK A GECTI (test edildi) *********************************
    vv  = 15597.96  -> Mov(C,2,VAR) calisiyor, VIDYA tipinin adi VAR.
    tt  = 6124      -> ref ile BIREBIR AYNI cikti (iki cizgi ust uste).
    ref = 6124

    Yani PREV, ATANDIGI DEGISKENIN gecmisine baglaniyor. Bunun sonuclari:
      - OTT ratchet'i calisir
      - Sistem / Explorer kosullari kendi kendine yeterlidir, kodu kayitli

{ ===== BLOK A - EN KRITIK: VAR (VIDYA) ortalamasi ve PREV baglanmasi =====
  1. cizgi (vv)  : Mov(C,2,VAR) -> fiyati yakindan takip eden bir egri
                   olmali. HATA verirse VAR tipinin adi farklidir
                   (VAR / Var / VIDYA / V). Hata mesajini bana yollayin.

  2. cizgi (tt)  : PREV testi. Beklenen: tt, "bar numarasi - 1" ile
                   BIREBIR AYNI olmali.
  3. cizgi (ref) : Cum(1)-1, yani beklenen deger.

     tt ile ref UST USTE binerse -> PREV, atandigi degiskenin gecmisine
     baglaniyor demektir. OTT ratchet'i calisir, sistem kosullari
     kendi kendine yeterlidir.

     tt duz 0 kalir veya ref'ten saparsa -> PREV farkli davraniyor.
     Bu durumda OTT-A'yi kayitli indikator yapip sistemde cagirmak gerekir;
     bana haber verin, kodu ona gore bolerim.
  ======================================================================== }

vv:=Mov(C,2,VAR);
tt:=If(Cum(1)=1,0,PREV+1);
ref:=Cum(1)-1;

vv;tt;ref;


{ ===== BLOK B - RATCHET (OTT'nin kalbi) ==================================
  Yukaridaki bloku silip bunu deneyin. Sabit opt ile klasik OTT'dir.
  Fiyati basamak basamak takip eden, hic geri gitmeyen bir merdiven
  gorunmeli. Duz cizgi veya fiyatin aynisi cikarsa PREV zinciri kopuktur.
  ======================================================================== }

{
opt:=1.4;
C1:=Mov(C,2,VAR);
q1:=Ref(C1,-2)*(1+opt/200);
q2:=Ref(C1,-2)*(1-opt/200);
If(Cum(1)=1,C1,If(q1<=PREV,q1,If(q2>=PREV,q2,PREV)));
C1
}
