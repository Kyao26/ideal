{ ==============================================================
  VWAP FİLTRESİ — Matriks Prime (Explorer / Tarama)
  Seans VWAP'ı + hacim ağırlıklı standart sapma bantları.
  Tipik fiyat olarak W (AOF) kullanılır, (H+L+C)/3 değil.

  KULLANIM: Gün içi periyotta çalıştırın (1dk/5dk/15dk...).
            Günlük periyotta her bar yeni gündür, seans reset'i
            anlamsızlaşır ve VWAP W'ye çöker.

  DURUM:    Söz dizimi Prime kılavuzuna göre doğrulandı
            (fonksiyon adları, parametreler, operatörler).
            Formül Prime'da ÇALIŞTIRILARAK test edilmedi.
  ============================================================== }


{ ---------- 1) Gün dönümü tespiti ---------- }
yeniGun := DAYOFMONTH() <> REF(DAYOFMONTH(), -1);


{ ---------- 2) Gün başındaki birikimler ----------
  CUM() grafiğin başından birikir ve seansta sıfırlanmaz.
  Dünkü son bardaki birikimi saklayıp bugünkünden çıkarıyoruz.
  VALUEWHEN'de N=1 en son (en yakın geçmiş) oluşumu verir. }
d := VALUEWHEN(1, yeniGun, REF(CUM(W*V), -1));
f := VALUEWHEN(1, yeniGun, REF(CUM(V), -1));
g := VALUEWHEN(1, yeniGun, REF(CUM(W*W*V), -1));
b := VALUEWHEN(1, yeniGun, REF(CUM(1), -1));


{ ---------- 3) Seans VWAP'ı ----------
  hac için sıfıra bölme koruması konuldu. }
hacHam := CUM(V) - f;
hac    := MAX(hacHam, 1);
vwap   := (CUM(W*V) - d) / hac;


{ ---------- 4) Hacim ağırlıklı varyans ve bantlar ----------
  Var = E[x²] - (E[x])²  — kümülatif, hacim ağırlıklı.
  Negatife düşmesi kayan nokta hatasıdır, MAX ile kırpıyoruz.
  Karekök fonksiyonu Sqr'dir; Prime'da SQRT yoktur. }
varHam := (CUM(W*W*V) - g) / hac - vwap * vwap;
sap    := Sqr(MAX(varHam, 0));

ust1 := vwap + sap;
alt1 := vwap - sap;
ust2 := vwap + 2 * sap;
alt2 := vwap - 2 * sap;


{ ---------- 5) Erken seans gürültü filtresi ----------
  Seansın ilk barlarında payda küçüktür, VWAP zıplar.
  CUM(1) grafiğin başından her bar 1 ekler; gün başındaki
  değeri çıkarınca günün kaçıncı barında olduğumuz kalır. }
barNo   := CUM(1) - b;
seansOk := barNo >= 6 AND hacHam > 0;


{ ---------- 6) FİLTRE ÇIKTISI ----------
  Aktif koşul: fiyat seans VWAP'ını yukarı kesti. }
seansOk AND CROSS(C, vwap)



{ ==============================================================
  ALTERNATİF SON SATIRLAR
  Yukarıdaki 6. bölümün son satırını bunlardan biriyle değiştirin.
  1-5. bölümler aynı kalır.
  ==============================================================

  { VWAP aşağı kesişimi — gün içi kontrol satıcılara geçti }
  seansOk AND CROSS(vwap, C)

  { Alt 2σ bandına sarkma — ortalamaya dönüş adayı (long) }
  seansOk AND C <= alt2

  { Üst 2σ bandı üstü — aşırı uzaklaşma (short / kar al bölgesi) }
  seansOk AND C >= ust2

  { Alt banda sarkıp geri dönüş — dönüş teyitli mean reversion }
  seansOk AND REF(C, -1) < alt2 AND C > alt2

  { Sağlıklı trend: VWAP üstünde ama henüz uca gitmemiş }
  seansOk AND C > vwap AND C < ust2

  { VWAP üstünde tutunma — son 3 bar boyunca üstte kaldı }
  seansOk AND C > vwap AND REF(C,-1) > REF(vwap,-1) AND REF(C,-2) > REF(vwap,-2)

  { Bantlar arası konum > %80 (üst uca yakın) }
  seansOk AND (C - alt2) / (ust2 - alt2) > 0.8

  ============================================================== }



{ ==============================================================
  SÖZ DİZİMİ NOTLARI (kılavuzdan teyitli)
  ==============================================================

  VALUEWHEN(N, koşul, değer)
      N=1 en son (en yakın geçmiş) oluşumu verir, en eskisini
      değil. Parametre "1" olarak yazılır — "1." değil.

  CUM(1)
      Grafiğin başından itibaren her bar için 1 ekler.
      Bar sayacı olarak kullanılır.

  Sqr(Data)
      Karekök. Prime'da SQRT DİYE BİR FONKSİYON YOKTUR.
      Alternatif: Power(Data, 0.5)

  MAX(Data1, Data2)
      İki değerden büyüğünü verir. If(x>0,x,0) yerine MAX(x,0)
      aynı işi tek satırda yapar.

  AND / OR
      Mantıksal operatörler. && ve || Prime'da yoktur.

  W
      Yerleşik veri serisi — barın ağırlıklı ortalaması (AOF).
      Tanımlamaya gerek yoktur, periyoda göre gelir.

  ============================================================== }


{ ==============================================================
  ÇALIŞTIRMADAN ÖNCE GÖZLE KONTROL
  ==============================================================

  1) Grafiğin ilk gününde VALUEWHEN henüz bir oluşum bulamaz;
     d/f/g/b boş dönerse ilk gün sonuçlarını dikkate almayın.

  2) barNo'nun günün ilk barında 1 geldiğini bir sembolde
     doğrulayın (gün reset'inin yerini kanıtlar).

  3) Taradığınız sembollerde W verisinin dolu geldiğini kontrol
     edin. Boş gelirse (H+L+C)/3'e düşmek gerekir.

  ============================================================== }
