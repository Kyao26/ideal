{ ==============================================================
  VWAP FİLTRESİ — Matriks Prime (Explorer / Tarama)
  Seans VWAP'ı + hacim ağırlıklı standart sapma bantları.

  DURUM
    Söz dizimi   : Prime kullanım kılavuzuna göre teyitli.
    Sayısal      : X30YVADE 5dk / 7.516 bar üzerinde ölçüldü,
                   iki geçişli kesin hesapla karşılaştırıldı.
    Çalıştırma   : Prime'da uçtan uca test EDİLMEDİ.

  KULLANIM
    Gün içi periyotta çalıştırın (1dk/5dk/15dk...).
    Günlük periyotta her bar yeni gündür, seans reset'i
    anlamsızlaşır ve VWAP WP'ye çöker.

  NEDEN KAYDIRMALI HESAP — bkz. dosya sonundaki ÖLÇÜM bölümü.
  Ham E[x²]-E[x]² formu float32'de çöküyor. Kaydırma zorunlu.
  ============================================================== }


{ ---------- 1) Tipik fiyat ----------
  W = AOF, borsanın bar için yayımladığı gerçek hacim ağırlıklı
  fiyat. Boş gelirse hlc3'e düşülüyor. }
WP := If(W > 0, W, (H+L+C)/3);


{ ---------- 2) Gün dönümü ve gün sayacı ---------- }
YGUN := DAYOFMONTH() <> Ref(DAYOFMONTH(), -1);
GSAY := Cum(If(YGUN, 1, 0));


{ ---------- 3) Gün başı referansı (kaydırma tabanı) ----------
  Dünkü son kapanış. Gün İÇİNDE sabittir — kaydırma
  algebrasının çalışmasının tek şartı budur. }
KAY := ValueWhen(1, YGUN, Ref(C, -1));
XD  := WP - KAY;


{ ---------- 4) Gün başındaki birikimler ----------
  CUM() grafiğin başından birikir, seansta sıfırlanmaz.
  Dünkü son bardaki birikimi saklayıp bugünkünden çıkarıyoruz.
  ValueWhen'de N=1 en son (en yakın geçmiş) oluşumu verir.

  Cum tüm geçmişi toplarken her bar kendi gününün KAY'ını
  kullanır; ama gün başındaki değer çıkarılınca geriye yalnızca
  bu gün kalır ve bu gün içinde KAY sabittir. Telescoping temiz. }
d := ValueWhen(1, YGUN, Ref(Cum(XD*V), -1));
f := ValueWhen(1, YGUN, Ref(Cum(V), -1));
g := ValueWhen(1, YGUN, Ref(Cum(XD*XD*V), -1));
b := ValueWhen(1, YGUN, Ref(Cum(1), -1));


{ ---------- 5) Seans VWAP'ı ----------
  ORTX = vwap - KAY. Sonunda KAY geri ekleniyor, değer birebir
  ham formülünkiyle aynı. }
DHAC := Cum(V) - f;
ORTX := If(DHAC > 0, (Cum(XD*V) - d) / DHAC, 0);
vwap := If(DHAC > 0, KAY + ORTX, C);


{ ---------- 6) Hacim ağırlıklı varyans ve bantlar ----------
  Varyans kaydırmaya duyarsızdır: Var(x-K) = Var(x).
  Karekök Sqr()'dir; Prime'da SQRT yoktur.
  MAX(VARY,0) kalan kayan nokta artığını kırpar. }
VARY := If(DHAC > 0, (Cum(XD*XD*V) - g) / DHAC - ORTX*ORTX, 0);
sap  := Sqr(MAX(VARY, 0));

ust1 := vwap + sap;
alt1 := vwap - sap;
ust2 := vwap + 2 * sap;
alt2 := vwap - 2 * sap;


{ ---------- 7) Seans geçerlilik guard'ı ----------
  GSAY>=2 : ilk günü eler. Ref(DAYOFMONTH(),-1) grafiğin ilk
            barında ne dönerse dönsün güvenli; ayrıca grafik
            seans ortasından başlarsa kısmi ilk günü de eler.
  barNo>=6: erken seansta payda küçüktür, VWAP zıplar. }
barNo := Cum(1) - b;
SOK   := GSAY >= 2 AND barNo >= 6 AND DHAC > 0;


{ ---------- 8) Yön kapıları ---------- }
LFIL := SOK AND C > vwap;
SFIL := SOK AND C < vwap;


{ ---------- 9) FİLTRE ÇIKTISI ----------
  Tek başına VWAP taraması için aktif satır: }
LFIL AND Cross(C, vwap)



{ ==============================================================
  SİSTEME BAĞLAMA
  Kendi sisteminizin tetikleyicisiyle birlikte kullanırken
  9. bölümün yerine:

      AL         : Cross(C, ST) AND TF AND LFIL
      Açığa Sat  : Cross(ST, C) AND TF AND SFIL
      SAT / Poz. kapama : dokunulmuyor

  ST ve TF bu dosyada TANIMLI DEĞİLDİR — kendi sisteminizden
  gelir (ST: trend hattı, TF: zaman filtresi). LFIL/SFIL burada
  yalnızca VWAP tarafındaki kapıyı üretir.
  ============================================================== }



{ ==============================================================
  ALTERNATİF SON SATIRLAR
  9. bölümün son satırını bunlardan biriyle değiştirin.
  1-8. bölümler aynı kalır.
  ==============================================================

  { VWAP aşağı kesişimi }
  SFIL AND Cross(vwap, C)

  { Alt 2σ bandına sarkma — ortalamaya dönüş adayı (long) }
  SOK AND C <= alt2

  { Üst 2σ bandı üstü — aşırı uzaklaşma }
  SOK AND C >= ust2

  { Alt banda sarkıp geri dönüş — dönüş teyitli mean reversion }
  SOK AND Ref(C,-1) < alt2 AND C > alt2

  { Sağlıklı trend: VWAP üstünde ama henüz uca gitmemiş }
  SOK AND C > vwap AND C < ust2

  { VWAP üstünde tutunma — son 3 bar }
  SOK AND C > vwap AND Ref(C,-1) > Ref(vwap,-1) AND Ref(C,-2) > Ref(vwap,-2)

  { Bantlar arası konum > %80 }
  SOK AND (C - alt2) / (ust2 - alt2) > 0.8

  ============================================================== }



{ ==============================================================
  ÖLÇÜM — neden kaydırmalı hesap
  X30YVADE 5dk, 7.516 bar. Cum-farkı yöntemiyle hesaplanan sap,
  iki geçişli kesin hesapla karşılaştırıldı.

    Kurgu                  Duyarlık   Ort hata   p95 hata     sap=0
    ---------------------  ---------  ---------  -----------  ------
    Ham (kaydırmasız)      float32    %85        %155-252     %17-21
    Ham (kaydırmasız)      float64    %0,000     %0,000       %0
    Gün başına kaydırılmış float32    %0,26      %0,28        %0
    Gün başına kaydırılmış float64    %0,000     %0,000       %0

  V=1 ve V=1741 sabit hacimle iki kez koşuldu, sonuç aynı:
  belirleyici olan hacim büyüklüğü değil FİYAT büyüklüğü.

  Ham formülün çökme biçimi sinsidir: float32'de barların
  beşte birinde VARY negatife düşer, MAX(VARY,0) bunu 0'a
  kırpar, sap sıfırlanır, bantlar VWAP'a yapışır ve bant
  koşulları hiç tetiklenmez — hata mesajı YOKTUR.

  Prime'ın içeride hangi duyarlığı kullandığı bilinmiyor.
  Kaydırma bu soruyu gereksiz kılıyor, maliyeti sıfır ve
  sabit K gerektirmediği için çok sembollü taramada da sorunsuz.

  vwap neden ham formülde bile sağlamdı: birinci moment
  oranında çıkarma hatası günün toplamına göre küçük kalır.
  Varyansta ise SONUCUN KENDİSİ iki büyük sayının küçük farkı
  olduğu için aynı mutlak hata sonucu yutar.
  ============================================================== }



{ ==============================================================
  KALAN RİSK VE TEŞHİS

  1) float32'de kaydırılmış sürümde bile %0,26 artık hata var.
     Mekanizma yok olmadı, 6.800 kat küçüldü. Biriken toplam
     grafik uzadıkça büyümeye devam ederken günlük pencere
     sabit kaldığı için hata bar sayısıyla ölçeklenir.
     Çok daha uzun bir geçmiş yüklerseniz yeniden ölçün.

  2) Teşhis: MAX guard'ını geçici olarak kaldırıp ham VARY'yi
     çizdirin. Kaydırılmış sürümde negatife SARKMAMALI.
     Sarkıyorsa Prime içeride beklenmedik bir şey yapıyordur.

  3) sap şu an filtre kapısına bağlı değil — mevcut kapı
     yalnızca vwap kullanıyor. Bant varyantı (ör. C > vwap +
     OPT1*sap) devreye alındığı gün bu düzeltme kritik hale
     gelir; şimdi hazır.

  4) Taranan sembollerde W verisinin dolu geldiğini gözle
     doğrulayın. Boşsa WP zaten hlc3'e düşer ama VWAP'ın
     anlamı zayıflar.
  ============================================================== }
